# HR Talent Insights & Attrition Analysis Dashboard
## Project Overview:
This Power BI dashboard provides a deep dive into employee attrition and workforce demographics. It helps HR managers understand why employees are leaving and which factors (like Age, Salary, or Overtime) are most influential.
## Key Insights from the Data:
- **Attrition Rate:** Identified key segments with high turnover.
- **Demographics:** Most attrition occurs in the **25-35** age group.
- **Job Satisfaction:** A clear correlation between **Overtime** and lower job satisfaction levels.
- **Income Level:** Higher attrition is observed in roles with lower average monthly income.
## Tools & Technologies Used:
- **Power BI Desktop:** For data visualization and DAX.
- **DAX (Data Analysis Expressions):** Created custom columns like `Age Group` and measures for `Total Employees`.
- **Power Query:** Used for data cleaning and transformation.
- **Dataset:** HR Analytics Employee Attrition data.
## Dashboard Preview:https://github.com/jweel-hossain/HR-Analytics-Dashboard-PowerBI/blob/main/HR%20Analytics%20Dashboard1.PNG

## Key Features:
- **Interactive Slicers:** Filter data by Department, Business Travel,JobRole and Overtime.
- **Satisfaction Matrix:** Heatmap showing job satisfaction across different roles.
- **Salary Analysis:** Scatter plot showing the correlation between Age and Monthly Income.
- **KPI Cards:** Instant overview of Total Employees, Attrition, and Avg Tenure.

## How to View this Project
